# Карточка товара Teaboom

Тестовое задание: адаптивная карточка товара «Ананасовый улун» по мотивам
действующего сайта [Teaboom.ru](https://teaboom.ru/product/ananasovij-ulun).

## Запуск

Проект не требует установки зависимостей или сборки. Откройте `index.html`
в браузере либо запустите локальный сервер:

```bash
python3 -m http.server 4177
```

После запуска страница будет доступна по адресу <http://localhost:4177>.

## Технологии

- HTML5;
- CSS3;
- JavaScript.
