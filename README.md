# Карточка товара Teaboom

Тестовое задание: адаптивная карточка товара «Ананасовый улун» в стилистике
действующего сайта [Teaboom.ru](https://teaboom.ru/product/ananasovij-ulun).

**Демо:** [wightles.github.io/teaboom](https://wightles.github.io/teaboom/)

## Возможности

- переключение между четырьмя фасовками;
- обновление артикула, актуальной и старой цены;
- состояния наведения и клавиатурного фокуса;
- адаптивная сетка для desktop, tablet и mobile;
- семантическая HTML-разметка и доступные элементы формы.

## Запуск

Проект не требует установки зависимостей или сборки. Откройте `index.html`
в браузере либо запустите локальный сервер:

```bash
python3 -m http.server 4177
```

После запуска страница будет доступна по адресу <http://localhost:4177>.

## Технологии

- HTML5;
- CSS3 с Grid и Flexbox;
- JavaScript без библиотек и фреймворков.

## Структура проекта

```text
├── assets/                # Изображения
├── scripts/product.js     # Переключение вариантов товара
├── styles/styles.css      # Стили и медиазапросы
├── index.html             # Страница карточки товара
└── README.md
```

Верстка проверена на ширинах 1440, 768 и 375 px.
